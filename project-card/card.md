GodotCascade is an experimental retained-mode UI toolkit for Godot 4: HTML/CSS-inspired `.gxml` markup and `.gcss` stylesheets compile through a parser/builder/reconciler pipeline into native `Control` nodes, with flex/grid/stack layout, one- and two-way bindings, and source-watching hot reload that preserves node identity. It is an experimental public preview (0.8.1) with a working addon, editor tooling, and a headless test suite, positioned as an alternative to GTML and similar Godot declarative-UI projects rather than a browser engine.
