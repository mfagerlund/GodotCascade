# GodotCascade addon

GodotCascade is an experimental retained-mode UI framework for Godot 4.7. It builds native Godot `Control` trees from focused GXML markup and GCSS styles, with deterministic flex/grid/table layout, bindings, keyed hot reload, and source-aware diagnostics.

After copying this directory to `res://addons/godot_cascade/`, enable **GodotCascade** under **Project → Project Settings → Plugins**. Then follow the [getting-started guide](https://github.com/mfagerlund/GodotCascade/blob/main/docs/getting-started.md) or open the showcase in the source repository.
