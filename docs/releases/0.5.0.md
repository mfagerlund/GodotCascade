# GodotCascade 0.5.0

GodotCascade 0.5.0 adds focused reactivity and conditional composition while retaining the source-format version 1 contract and Godot 4.7 target.

## Install

Download `godot-cascade-0.5.0.zip`, extract it at the root of a Godot project so `addons/godot_cascade/plugin.cfg` exists, then enable **GodotCascade** under **Project → Project Settings → Plugins**.

## Highlights

- `ObservableBindingContext` explicitly invalidates exact parent/child paths without polling or a general expression runtime.
- One-way bindings now cover visibility, disabled and checked state, select values, image sources, and dynamic class lists in addition to text and ranges.
- Bound classes rematch GCSS selectors through an off-tree candidate while keyed reconciliation preserves compatible native controls.
- Exact boolean `if="{path}"` conditions include or omit native subtrees and retain dependency metadata even while a branch is absent.
- Document validation, binding compilation, and declaration application are split out of the builder into focused runtime services.
- The typed C# generator supports directly assignable `visible` and `disabled` targets alongside its existing text, range, checked, selected, and writable targets.
- A reproducible native live-reload artifact demonstrates actual source edits, native Control-tree output, and preserved engine instances.
- Reconciler property parity, Unicode diagnostic offsets, deterministic packaging, generated showcase references, and clean-install coverage have additional regression guards.
- The cascading-native-windows project identity now has deterministic SVG and small-size-tested PNG assets.

## Compatibility and boundaries

Version 0.5 is backward-compatible with the documented 0.4 source surface. Existing markup does not require migration.

Named invalidation is explicit rather than automatic dependency tracking. Documents containing `Repeat` conservatively rebuild a candidate because collection topology may have changed. Runtime `{path}` supports bound `class` and `Image.src`; generated C# intentionally limits itself to directly assignable targets.

Conditional rendering accepts only exact boolean paths. There are no comparisons, negation, method calls, truthy coercion, implicit `else`, or general expressions. Stable siblings reconcile in place, but controls inside a removed branch are freed and newly created if the condition later becomes true.

Clipboard, undo/redo, IME, touch, and screen-reader behavior remains native to Godot and carries the platform-dependent limits recorded in the [TextInput certification matrix](../text-input-certification.md). Those rows are not claimed as manually certified on every platform.
