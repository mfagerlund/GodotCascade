# GodotCascade 0.1.0

GodotCascade 0.1.0 is the first public preview of the retained-mode GXML/GCSS UI framework for Godot 4.7.

## Install

Download `godot-cascade-0.1.0.zip`, extract it at the root of a Godot project so `addons/godot_cascade/plugin.cfg` exists, then enable **GodotCascade** under **Project → Project Settings → Plugins**.

The release archive contains the addon only. Examples, tests, benchmarks, and documentation remain in the source repository.

## Highlights

- Native Godot control trees generated from focused GXML and GCSS.
- Flex, grid, stack, media-query, viewport-unit, and absolute layout.
- Owned form controls with keyboard/controller interaction and shared pseudo states.
- Identity-preserving hot reload, explicit one-way bindings, repeats, and authored events.
- Editor importers, live preview, Inspector metadata, layout snapshots, and source navigation.
- Automated native/HTML showcase parity, accessibility checks, and performance budgets.

## Compatibility and limits

Godot 4.7 is the tested editor version. Source format version 1 and the documented 0.1 runtime surface follow the [public-preview stability policy](../api-stability.md). `TextInput`, writable bindings, validation state, and browser-wide CSS compatibility are not part of this release.
