# GodotCascade 0.2.0

GodotCascade 0.2.0 adds a complete interactive-forms slice while retaining the 0.1 source-format contract and Godot 4.7 target.

## Install

Download `godot-cascade-0.2.0.zip`, extract it at the root of a Godot project so `addons/godot_cascade/plugin.cfg` exists, then enable **GodotCascade** under **Project → Project Settings → Plugins**.

## Highlights

- Adapted native single-line `TextInput` with placeholder, read-only, disabled, secret, max-length, accessibility, and editing-state preservation.
- Required and regular-expression validation with `:invalid` appearance and document-level validation diagnostics.
- Explicit writable `bind-text`, `bind-checked`, `bind-value`, and `bind-selected` paths.
- Input-modality-aware `:focus-visible` borders for interactive controls.
- Interactive native and HTML settings showcases with live scale/status output and an Apply workflow.
- Backward-compatible cached showcase references and expanded clean-install verification.

## Compatibility

The minimum tested engine remains Godot 4.7 and GXML/GCSS source format remains version 1. Existing exact `{path}` attributes remain one-way; write-back occurs only through explicit `bind-*` attributes.

`TextInput` is currently single-line. `multiline="true"`, writable bindings inside `Repeat`, and arbitrary-container pseudo states remain deferred. Clipboard, undo/redo, IME, touch, and screen-reader behavior stays native to Godot and carries the platform-dependent limits recorded in the [TextInput certification matrix](../text-input-certification.md).
