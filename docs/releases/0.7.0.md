# GodotCascade 0.7.0

GodotCascade 0.7.0 adds scale-oriented retained collections, fixed-height virtualization, advanced focused styling, and complete source-language tooling while retaining source-format version 1 and the Godot 4.7 minimum.

## Install

Download `godot-cascade-0.7.0.zip`, extract it at the root of a Godot project so `addons/godot_cascade/plugin.cfg` exists, then enable **GodotCascade** under **Project → Project Settings → Plugins**.

## Highlights

- `CascadeItemModel` and the included `CascadeArrayItemModel` publish typed insert, remove, move, update, and reset changes without polling.
- Collection-only changes build and reconcile affected outer Repeat candidates rather than a complete off-tree document.
- Fixed-height vertical list and semantic-table virtualization keeps 10,000-item models bounded to the visible range, overscan, native spacers, and at most one key-pinned focused row.
- Collection transactions reject missing/duplicate keys, malformed deltas, invalid nested-model transitions, unsafe bound row geometry, and multi-Repeat partial commits while retaining the last valid native tree.
- GCSS adds flex shrink/basis, opacity, container-safe transforms, two-stop linear gradients, inherited project-local fonts, and project-local SVG textures through Godot's native importer.
- GXML adds authored autofocus, tab order, and modal focus traps with deterministic diagnostics and restoration.
- Godot and dependency-free VS Code tooling now cover completion, hover, formatting, definitions, safe rename, and diagnostics.
- The runnable showcase adds a 10,000-item virtual inventory page in both generated HTML and native Godot output.
- CI runs the full gate on Godot 4.7.1/Linux plus minimum 4.7/Linux and current Windows/macOS runtime smoke jobs.

## Evidence and limits

The [representative workload report](../artifacts/representative-workload-benchmark-2026-08-07.md) records complete-operation medians for the settings, dashboard, leaderboard, and 10,000-item inventory scenes against hand-authored native alternatives. These totals include cold construction and two settling frames; none is a per-frame number.

The reproducible [deployment-queue comparison with GTML](../artifacts/godotcascade-vs-gtml-deployment-queue.md) verifies the same non-showcase workflow in both projects. The 0.7.0 tag passed but was materially slower for fine-grained scalar and keyed-list updates. The linked report now preserves those release measurements beside a post-0.7 main-branch rerun after retained dependency routing and pure keyed reorders were implemented.

Virtualization is vertical and fixed-height only. Variable-height, horizontal, wrapped, and arbitrary ephemeral-row-state virtualization are not supported. See the [collection contract](../collections.md) before enabling `virtual="true"`.

Clipboard, undo/redo, IME, touch, virtual-keyboard, and screen-reader behavior remains delegated to native Godot controls and is not manually certified by headless desktop CI. Follow the [platform certification protocol](../platform-certification.md) for real hardware and assistive-technology evidence.
