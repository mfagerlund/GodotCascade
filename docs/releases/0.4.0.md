# GodotCascade 0.4.0

GodotCascade 0.4.0 completes the typed-binding and semantic-table slices while retaining the source-format version 1 contract and Godot 4.7 target.

## Install

Download `godot-cascade-0.4.0.zip`, extract it at the root of a Godot project so `addons/godot_cascade/plugin.cfg` exists, then enable **GodotCascade** under **Project → Project Settings → Plugins**.

## Highlights

- Optional typed C# partial generation from GXML `Bindings`, including explicit getters/setters, verbatim formatter/parser bodies, source mappings, native signal wiring, feedback suppression, and hot-reload reconnection.
- Typed Godot object models are now the recommended runtime binding pattern while Dictionary and JSON-shaped paths remain supported.
- Semantic `Table`, `TableHeader`, `TableBody`, `TableRow`, `TableHeaderCell`, and `TableCell` elements with shared fixed, content, fractional, and `minmax()` column tracks.
- Keyed repeated table rows, accessible cell metadata, deterministic focus behavior, and clean inherited outer header corners.
- An adapted native `Scroll` element with automatic vertical overflow and a bounded minimum-size contract for growing content.
- A dynamic HTML/Godot leaderboard showcase covering typed add/remove/sort operations plus reliable captured-pointer and keyboard row reordering.
- A complete binding guide and generated showcase source panels covering both declarative source and application interaction code.
- Form-control polish including compact select options, antialiased circular controls, complete slider hover feedback, and full-row repeated checkbox targets.
- Duplicate document-ID validation before reconciliation, including last-valid retention on invalid reloads.
- Automated .NET compilation of the generated C# example together with its user-owned partial.

## Compatibility

The minimum tested engine remains Godot 4.7 and GXML/GCSS source format remains version 1. Version 0.4 is backward-compatible with the documented 0.3 source surface; no existing markup migration is required.

Typed C# generation is optional and does not replace runtime property-path binding. `Scroll` requires exactly one content child and delegates wheel, touch, clipping, focus-following, and scrollbar behavior to native `ScrollContainer`. Tables remain semantic display tables: sorting, selection, resizing, and reordering are application-level behaviors rather than built-in data-grid features.

Clipboard, undo/redo, IME, touch, and screen-reader behavior remains native to Godot and carries the platform-dependent limits recorded in the [TextInput certification matrix](../text-input-certification.md). Those rows are not claimed as manually certified on every platform.
