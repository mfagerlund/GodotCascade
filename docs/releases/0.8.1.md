# GodotCascade 0.8.1

GodotCascade 0.8.1 is a review-driven hardening release for the Godot 4.7 experimental preview. It retains source-format version 1 while tightening diagnostics and correcting lifecycle, focus, collection, state-retention, accessibility, code-generation, editor-tooling, packaging, and certification edges found by independent Codex and Claude passes.

## Install

Download `godot-cascade-0.8.1.zip`, extract it at the root of a Godot project so `addons/godot_cascade/plugin.cfg` exists, then enable **GodotCascade** under **Project → Project Settings → Plugins**.

## Highlights

- GXML and GCSS parsing is quote-aware, source-located, and consistent across runtime, Godot tooling, and VS Code. The canonical schema now rejects unsupported built-in attributes and invalid root, Repeat, virtual, table, focus, and generated-binding structures without constraining registered custom controls.
- Compatible reloads and localized collection updates preserve native identity, focus, editing state, and live checkbox/radio/switch/select/slider values unless the corresponding authored declaration changes. Focus-trap-affecting changes remain atomic and fall back to a validated full candidate when required.
- Component detach/re-entry, writable diagnostics, collection transactions, virtual focus pinning, and reconciliation traces now have explicit lifecycle and failure contracts with regressions on Godot 4.7 and 4.7.1.
- Native accessibility roles and names cover the owned form, progress, and semantic-table surface. Platform announcements, IME, clipboard services, touch selection, and virtual keyboards remain manual certification gates.
- Typed C# generation validates binding declarations, C# identifiers, duplicate symbols, generated targets, and formatter/parser bodies. Generated method signatures and bodies compile normally; native control lookup and target assignment remain runtime-checked Godot operations.
- The dependency-free VS Code extension now mirrors the runtime schema and structural contracts, including lowercase built-ins, reusable/slotted table components, instance-scoped IDs, reserved names, and safe component rename. Workspace class/ID/custom-property rename is explicitly textual and preview-required.
- Release tooling packages tracked addon files deterministically, validates clean installation, pins CI actions and Godot archives, and distinguishes complete-operation benchmark totals from frame time.

## Compatibility notes

Strict path parsing and several newly enforced source contracts may expose previously silent mistakes. Read the [0.8.1 migration notes](../migrations.md) before upgrading source that uses unusual Dictionary keys, root conditionals, generated bindings inside Repeat, nested media, virtual item-root visibility, or dot-qualified C# class names.

The detailed independent findings, fixes, experiments, and residual manual gates are recorded in the [0.8.1 review-hardening report](../artifacts/review-hardening-2026-08-08.md).
