# GodotCascade 0.3.0

GodotCascade 0.3.0 completes the scoped and multiline forms slice while retaining the source-format version 1 contract and Godot 4.7 target.

## Install

Download `godot-cascade-0.3.0.zip`, extract it at the root of a Godot project so `addons/godot_cascade/plugin.cfg` exists, then enable **GodotCascade** under **Project → Project Settings → Plugins**.

## Highlights

- `TextInput multiline="true"` adapts native `TextEdit` editing, selection, clipboard, undo/redo, shaping, bidi, and IME behavior.
- Multiline validation, max length, writable binding, focus-visible styling, and text/caret/selection/scroll preservation.
- Writable `item.<path>` bindings inside keyed `Repeat` templates, including correct write identity after reordering.
- `:hover` background styling for owned Box/Panel, Grid, and Stack containers without adding activation or focus semantics.
- Settings showcase parity for multiline notes and repeated HUD checkboxes while retaining switch, slider, dropdown, and Apply interactions.
- A runnable manifest-driven Godot showcase app with page navigation, reload, live diagnostics, direct-page launching, and automated event-connection checks.
- Reconciliation now suppresses synthetic writable-control changes while applying authored state.
- Byte-for-byte reproducible Windows/Linux release archives and manifest-sized native showcase captures.

## Compatibility

The minimum tested engine remains Godot 4.7 and GXML/GCSS source format remains version 1. Version 0.3 is backward-compatible with the documented 0.2 source surface.

Password masking remains single-line-only. Inside `Repeat`, writable bindings must target an existing nested `item.<path>`; `index` and whole-item replacement remain read-only. Non-interactive containers support hover backgrounds only and do not gain pressed, disabled, focus, or activation behavior.

Clipboard, undo/redo, IME, touch, and screen-reader behavior remains native to Godot and carries the platform-dependent limits recorded in the [TextInput certification matrix](../text-input-certification.md). Those rows are not claimed as manually certified on every platform.
