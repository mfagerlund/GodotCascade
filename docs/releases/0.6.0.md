# GodotCascade 0.6.0

GodotCascade 0.6.0 adds reusable composition, observable debugger traces, and focused GCSS design tokens/arithmetic while retaining source-format version 1 and the Godot 4.7 target.

## Install

Download `godot-cascade-0.6.0.zip`, extract it at the root of a Godot project so `addons/godot_cascade/plugin.cfg` exists, then enable **GodotCascade** under **Project → Project Settings → Plugins**.

## Highlights

- Reusable source-level GXML components support checked parameters, default/named slots, scoped IDs, source-aware diagnostics, and identity-preserving reconciliation.
- Binding dependency and invalidation traces expose targeted updates versus keyed reconciliation in `CascadeDocument`, debugger snapshots, and the editor dock.
- Case-sensitive `--custom` declarations cascade and inherit through the authored tree without reaching native property application.
- Lazy `var(--name, fallback)` supports transitive values, nested fallback, pseudo-state overlays, cycles, source-located diagnostics, and cached diagnostic replay.
- Typed `calc()` supports NUMBER, LENGTH (`px`, `vw`, `vh`), and TIME (`ms`, `s`) arithmetic with parentheses, unary signs, and checked operators.
- Variable substitution occurs before shorthand expansion; invalid winning shorthands retain conceptual longhand precedence instead of exposing lower declarations.
- Computed-style cache keys include both viewport axes, preventing stale `vh` arithmetic when only viewport height changes.
- The layout showcase and README quickstart exercise the new grammar in both executable GCSS and paired HTML, while the expanded 500-control benchmark reports literal and expression-heavy cold-build costs separately.

## Compatibility and boundaries

Version 0.6 is backward-compatible with the documented 0.5 source surface. Existing markup and styles do not require migration.

This is a focused arithmetic contract, not browser CSS compatibility. Percentages, `em`/`rem`, `fr` arithmetic, dimensional multiplication/division, `min()`/`max()`/`clamp()`, `@property`, runtime variable bindings, transforms, gradients, and custom fonts remain unsupported. Variables and arithmetic resolve during document build/reload, not per frame.

Custom properties are case-sensitive; ordinary GCSS property names remain case-insensitive. A pseudo-state uses the element's base custom environment plus declarations authored for that state; parent pseudo-state environments do not propagate to children.

The selected semantics, rejected approaches, performance distribution, and exact verification evidence are recorded in the [custom-properties and typed-calc experiment](../artifacts/custom-properties-calc-experiments-2026-08-07.md).

Clipboard, undo/redo, IME, touch, and screen-reader behavior remains native to Godot and carries the platform-dependent limits recorded in the [TextInput certification matrix](../text-input-certification.md).
